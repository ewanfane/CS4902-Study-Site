# CS4092 Android Development Study Suite

## Overview
This purpose-built study environment is designed to streamline revision for the **CS4092** Android Development exam. It consolidates scattered course materials, lecture notes, and past exam papers into a unified, interactive Single Page Application (SPA) suite.

## Origin & AI Development
This project was architected and generated using **Structured AI Course Analysis**.

-   **Deep Content Analysis**: AI models parsed unstructured text files, lecture slides, and past exam papers to extract key concepts and recurring themes.
-   **Agentic Development**: The codebase was built using an advanced agentic coding assistant, utilizing rigorous planning (Implementation Plans) and verification steps to ensure accuracy.
-   **Learning Optimization**: Features such as "Smart Distractors" in the Quiz and "spaced repetition" concepts in Flashcards were implemented to maximize retention based on educational best practices.

## Features
-   **Course Guide (`course.html`)**: A narrative-driven overview of the entire syllabus, featuring interactive stacks and charts.
-   **Code Patterns (`code.html`)**: Syntax-highlighted snippets of essential Android implementations (RecyclerView, Intents, Services).
-   **Question Bank (`pastpapers.html`)**: A searchable, consolidated archive of past exam questions grouped by topic.
-   **Exam Simulator (`quiz.html`)**: An interactive MCQ engine with instant feedback and error-tracking.
-   **Flashcards (`flashcards.html`)**: Rapid-fire revision cards for key terms and definitions.
-   **Safety Net (`safety_net.html`)**: A collection of "gotcha" topics and frequently missed details.

## Tech Stack
-   **Core**: HTML5, JavaScript (ES6+)
-   **Styling**: Tailwind CSS
-   **Visualization**: Chart.js
-   **Deployment**: Static Site (Zero backend dependencies)
