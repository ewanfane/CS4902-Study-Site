01.RecyclerView Adapter

HIGH PRIORITY

The standard boilerplate for listing items. You MUST know onCreateViewHolder, onBindViewHolder, and getItemCount.

public class MyAdapter extends RecyclerView.Adapter<MyAdapter.ViewHolder> {

    private List<String> data;

    // 1. Inflate the Row Layout
    @Override
    public ViewHolder onCreateViewHolder(ViewGroup parent, int viewType) {
        View v = LayoutInflater.from(parent.getContext())
                  .inflate(R.layout.row_item, parent, false);
        return new ViewHolder(v);
    }

    // 2. Bind Data to Views
    @Override
    public void onBindViewHolder(ViewHolder holder, int position) {
        holder.txtTitle.setText(data.get(position));
    }

    // 3. Return Count
    @Override
    public int getItemCount() {
        return data.size();
    }
}

03.Database Background Thread

CORE CONCEPT

The "ANR Prevention" code. You can use Thread or Executors.

public void savaData(User user) {
    new Thread(() -> {
        
        // 1. Database Work (Background)
        db.userDao().insert(user);

        // 2. Update UI (Main Thread)
        runOnUiThread(() -> {
             Toast.makeText(this, "Saved!", LENGTH_SHORT).show();
        });

    }).start();
}

04.Implicit Intent

MAPS/WEB

Launching external apps like Maps or Browser.

public boolean onLongClick(View v) {
    // 1. Format URI
    String loc = building.getLocation();
    Uri uri = Uri.parse("geo:0,0?q=" + loc);

    // 2. Create Intent
    Intent mapIntent = new Intent(Intent.ACTION_VIEW, uri);

    // 3. Launch
    v.getContext().startActivity(mapIntent);
    return true;
}
