Definition

A Smart Cellular Phone is essentially a Radio + Computer.

Open Source

Android is Linux-based, developed by Google & the Open Handset Alliance.

Market

Dominant globally, though iOS competes strongly in North America & Ireland.

3. The Four Core Components

Every Android app is constructed from these building blocks.

📱

Activity

HAS UI

A single visual screen. The entry point for interaction.

⚙️

Service

NO UI

Runs background 'busy work' indefinitely (Music, GPS).

📡

Broadcast Receiver

NO UI

System-wide listener. Reacts to 'Battery Low' or 'WiFi Connected'.

🗄️

Content Provider

NO UI

Manages shared app data (like Contacts) via standard query methods.

4. The Activity Lifecycle

Understanding state transitions is critical for preventing crashes.

RUNNING Visible & Focused
onPause()
PAUSED Partially Visible ⚠️ Killable by OS
onStop()
STOPPED Hidden
onDestroy()

onCreate()

Mandatory. Runs once. Setup your UI (setContentView) and wire up variables here.

onPause() - CRITICAL

Highly Recommended. This is the last guaranteed safe spot to save persistent data before the OS might kill your app to save memory.

The Stack

Activities live in a "Task Stack". New ones go on top. The 'Back' button pops the top one off.

5. Data Persistence

Choosing the right storage option based on structure and access needs.

SharedPreferences

Small key-value pairs (Settings, High Scores). Private.

Internal Storage

Private files. Good for blobs and caches.

External Storage (SD Card)

Large public media (Photos, Music). Requires permissions.

SQLite / Room

Structured, complex data. Room provides compile-time verification.

⚡ The Golden Rule of Concurrency

"NEVER perform long-running operations (Network, Database) on the Main UI Thread."
Consequence

Freezes the app. Causes ANR (Application Not Responding) crash.

Solution 1

Thread + Handler (Worker sends Message to Handler on Main).

Solution 2

AsyncTask (doInBackground for work, onPostExecute for UI).
