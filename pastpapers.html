RecyclerView & Adapters

  • ViewHolder Pattern: RecyclerView enforces the use of the ViewHolder pattern, which stores references to the views in a row. ListView did not enforce this, leading to inefficient findViewById() calls during scrolling.
  • Layout Managers: RecyclerView decouples the list layout from the container. You must assign a LayoutManager (Linear, Grid, or Staggered), whereas ListView was restricted to vertical lists.
  • Animations: RecyclerView has built-in support for item animations (add/remove), which ListView lacks.

1. Dependencies: Add RecyclerView library to build.gradle.

2. Layout XML: Add <RecyclerView> to Activity layout.

3. Row Layout: Create row_item.xml for single item design.

4. Create Adapter: Extend RecyclerView.Adapter.

5. Initialize: In Activity, find logic, set LayoutManager, and setAdapter.

1. onCreateViewHolder(parent, viewType)

Inflates the XML layout (row_item.xml). Analogy: Buying the blank canvas.

2. onBindViewHolder(holder, position)

Binds data from the list to the View using the Holder. Analogy: Painting the picture.

3. getItemCount()

Returns total items. RecyclerView needs this to know scrolling limits.

RecyclerView doesn't have a default OnItemClick. We use an Interface Approach:

  1. Define Interface: created inside Adapter (e.g. onItemClick(int pos)).
  2. Implement: Activity implements this interface.
  3. Pass: Pass Activity (this) to Adapter constructor.
  4. Trigger: In ViewHolder, set itemView.setOnClickListener to call the interface method.
@Override
protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    setContentView(R.layout.activity_main);

    // 1. Initialize
    RecyclerView rv = findViewById(R.id.myRecyclerView);

    // 2. Layout Manager (Crucial!)
    rv.setLayoutManager(new LinearLayoutManager(this));

    // 3. Adapter
    List<Person> data = db.getAll();
    MyAdapter adapter = new MyAdapter(data, this);
    rv.setAdapter(adapter);
}

Navigation & Intents

@Override
public void onClickItem(int position) {
   Person p = list.get(position); // 1. Get Object
   
   // 2. Explicit Intent
   Intent i = new Intent(this, EditActivity.class);
   
   // 3. Put Extras
   i.putExtra("id", p.getId());
   i.putExtra("name", p.getName());

   startActivity(i);
}
// In onCreate()
Bundle extras = getIntent().getExtras();
if (extras != null) {
    int id = extras.getInt("id");
    String name = extras.getString("name");
    
    // Populate UI
    nameField.setText(name);
}
Explicit Intent

You specify the exact component class. Used for internal navigation.

new Intent(this, DetailActivity.class);
Implicit Intent

You declare a general action (e.g., View URL). OS finds the app.

new Intent(Intent.ACTION_VIEW, Uri.parse("..."));

Database (SQLite & Room)

  1. Capture ID: Passed from List Activity. If -1, it's New. If >0, it's Edit.
  2. User Input: Get strings from EditText.
  3. Save: Call DB helper update(id, ...) or add(...).
  4. Finish: Close activity to return to list.
saveBtn.setOnClickListener(v -> {
    String name = nameInput.getText().toString();
    DatabaseHelper db = new DatabaseHelper(this);
    
    if (id != -1) {
        db.update(id, name);
    } else {
        db.add(name);
    }
    finish();
});

Steps to Room: 1. Dependencies, 2. @Entity, 3. @Dao, 4. @Database class, 5. Instance.

Why Background Thread?
DB ops are blocking. Running on Main Thread freezes UI → ANR Error.

Room Save Code:

saveBtn.setOnClickListener(v -> {
    Building b = new Building(nameInput.getText().toString());
    
    // 1. Thread necessary for DB
    new Thread(() -> {
        AppDatabase.get(this).dao().insert(b);
        
        // 2. UI Thread necessary to finish()
        runOnUiThread(() -> finish());
    }).start();
});

holder.itemView.setOnLongClickListener(v -> {
    String loc = list.get(pos).getLocation();
    
    // 1. Parse URI (geo:0,0?q=Dublin)
    Uri uri = Uri.parse("geo:0,0?q=" + loc);
    
    // 2. Implicit Intent
    Intent mapIntent = new Intent(Intent.ACTION_VIEW, uri);
    
    // 3. Launch
    v.getContext().startActivity(mapIntent);
    return true;
});
