Topic 1: The List Powerhouse

Why RecyclerView replaced ListView and how to implement it.

VS RecyclerView vs ListView

  • 📦
    ViewHolder Pattern

    Enforced by RecyclerView for efficiency. ListView didn't enforce it, leading to laggy scrolls.

  • 📐
    Layout Managers

    Decoupled layout logic. Choose Linear, Grid, or Staggered. ListView was vertical only.

  • ✨
    Animations

    Built-in support for item add/remove animations. ListView requires custom hacks.

The Adapter Trinity

The 3 core methods you MUST override in your Adapter.

1. onCreateViewHolder

Inflates XML layout. Analogy: Buying a blank canvas.

2. onBindViewHolder

Binds data at position to views. Analogy: Painting the canvas.

3. getItemCount

Returns total list size so the Recycler knows when to stop.

Topic 2: Navigation & Intents

Moving between screens (Activities) is fundamental. Understanding the difference between explicit instructions and vague requests is key.

Explicit Intents

You specify the exact target component.

// Navigating inside your app
new Intent(this, TargetActivity.class);

Implicit Intents

You declare an action; OS finds the app.

// Opening a URL
new Intent(Intent.ACTION_VIEW,
Uri.parse("http://google.com"));

Passing Data (The "Extras" Pattern)

How to send an ID from a List to a Detail view.

Sender (Activity 1)
intent.putExtra("id", person.getId());
startActivity(intent);
Receiver (Activity 2)
Bundle extras = getIntent().getExtras();
int id = extras.getInt("id");

⚠️ CRITICAL EXAM CONCEPT

Why use a Background Thread?

Database operations are "blocking". If you run them on the Main UI Thread, the app freezes. If it freezes for >5 seconds, you get an ANR (Application Not Responding) crash.

// The "Golden Rule" Pattern in Code
saveButton.setOnClickListener(v -> {
  new Thread(() -> {
    // 1. Heavy Work (Database)
    db.dao().insert(data);

    // 2. Update UI (Must be on UI Thread)
    runOnUiThread(() -> finish());
  }).start();
});

Advanced: Geo-Location Feature

Often appearing as "Question 1 Part 5" or "Question 2 Part 5". You need to launch a Map using an Implicit Intent.

  • Use ACTION_VIEW
  • Parse URI with geo:0,0?q=Location
  • Always resolve activity before starting to prevent crashes.
Uri gmmIntentUri = Uri.parse("geo:0,0?q=" + location);
Intent mapIntent = new Intent(Intent.ACTION_VIEW, gmmIntentUri);
startActivity(mapIntent);
